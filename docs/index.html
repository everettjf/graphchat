THE LEARNING LOOP

聊天会结束，
理解应该继续生长。

Graph Chat 保存的不只是消息，而是问题之间真正有用的关系。

01

从任意位置分叉

选中一句话，或从当前节点继续提问。新的探索拥有自己的上下文，不会把主线冲散。

02

引用另一个分支

把两个或更多节点加入联合提问。虚线边精确记录这次综合使用了哪些理解。

03

把答案带回主线

Pi agent 根据显式上下文运行模型与图谱工具，让新的理解可追溯、可继续、可复用。

PI AGENT LOOP

不是一次 API 调用。

流式回答、图谱搜索、节点读取、工具循环、重试和取消，都由 Pi agent harness 管理。
